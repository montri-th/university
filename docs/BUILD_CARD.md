## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** นักศึกษาที่ อว. รายงานกระจุกอยู่จังหวัดใด มากแค่ไหนเมื่อเทียบกับทั้งประเทศ ภาพเปลี่ยนแค่ไหนเมื่อไม่นับมหาวิทยาลัยเปิด และจังหวัดใดไม่มีหน่วยรายงานเลย ผู้ใช้เริ่มสำรวจระดับจังหวัดได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot รุ่น 0.1.1): **“55% ของนักศึกษาทั้งประเทศ อยู่ใน 3 จังหวัดนี้”** กรุงเทพมหานคร · ปทุมธานี · เชียงใหม่ — 988,359 จาก 1,786,753 คน · แท่งเทียบ: ทุกประเภท 55% · ไม่นับมหาวิทยาลัยเปิด (รามคำแหง · สุโขทัยธรรมาธิราช) 49% (710,594 จาก 1,460,444 คน) ฐานอยู่ในคำอธิบายของแท่ง · “ไม่มีหน่วยรายงาน 9 จังหวัด” พร้อมชื่อ ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดทั้งประเทศแบบแผนผัง: สีจังหวัด `li.supply` ครบ 41 ระดับ ขอบเน้นจังหวัดในข้อค้นพบ หมุดวิทยาเขตตามประเภท จุดทะเบียน 2566 และสถานีรถไฟฟ้าเป็นบริบทที่เงียบ

**One useful action:** “ดูทุกจังหวัดเท่ากัน” และ “เปรียบเทียบจังหวัด” (เปิดกราฟ) · สลับ “นักศึกษา | หน่วยรายงาน” ในคำอธิบายแผนที่: ข้อค้นพบเปลี่ยนเป็น “31% ของหน่วยรายงานทั้งประเทศ อยู่ใน 3 จังหวัดนี้” (กรุงเทพมหานคร 69 · นครปฐม 13 · เชียงใหม่ 11 — 93 จาก 303 หน่วย) · เลือกจังหวัด: ข้อค้นพบเปลี่ยนเป็นมหาวิทยาลัยที่มีนักศึกษามากที่สุดในจังหวัด (กรุงเทพมหานคร: 47% อยู่กับรามคำแหง จุฬาลงกรณ์ เกษตรศาสตร์ — 354,957 จาก 750,679 คน)

## Evidence cue and calculation

แหล่ง: `data/universities.json` (303 หน่วยรายงาน 1,786,753 คน) และ `data/area-index.json` (77 จังหวัด) การคำนวณ: `summarizeInsight` (`js/area-insight.js`) บนหน่วยรายงานที่ผ่าน `filterUnits`

| จังหวัด | รหัส | นักศึกษา |
|---|---|---:|
| กรุงเทพมหานคร | `BKK` | 750,679 |
| ปทุมธานี | `PTE` | 147,809 |
| เชียงใหม่ | `CMI` | 89,871 |

สัดส่วน = 988,359 ÷ 1,786,753 = 55% · แท่งที่สองไม่นับหน่วยรายงานประเภท `open` ทั้งในตัวตั้งและตัวหาร

**ไม่ตัดผ่านค่าเท่ากัน และไม่โฟกัสทุกจังหวัด:** ถ้าจังหวัดลำดับถัดไปมีค่าเท่ากับจังหวัดสุดท้ายที่แสดง โฟกัสเหลือเฉพาะจังหวัดที่มากกว่า ถ้าจังหวัดที่มีค่าไม่เกิน 3 จังหวัด โฟกัสเฉพาะ N − 1 จังหวัดบนสุด (`topWithoutTie`, `tests/insight.test.js`)

## States

| State | ผลบนหน้าจอ |
|---|---|
| โหลด | การ์ดเปิดเว็บ (`js/shell/launch.js`) จนข้อมูลพร้อม ธีมถูกตั้งก่อนภาพแรก |
| ไม่พบตามตัวกรอง | “ไม่พบหน่วยรายงานตามตัวกรอง” + ล้างตัวกรอง |
| จังหวัดที่ไม่มีหน่วยรายงาน | measured zero (ขอบไม่มีสี) · ข้อค้นพบบอกว่าไม่มีหน่วยรายงานในจังหวัดนี้ตามตัวกรอง |
| วิทยาเขตไม่มีหน่วยรายงานผูก | ไม่แสดงตัวเลขนักศึกษา (ไม่ใช่ 0) |
| ไฟล์วิทยาเขตยังไม่มา | “กำลังโหลดรายชื่อคณะ” ในหน้าวิทยาเขต (ไม่ว่างเปล่า) |
| ไฟล์วิทยาเขตโหลดไม่ได้ | แจ้ง “ข้อมูลไม่ครบ”: ไม่แสดงกรอบ คณะ หลักสูตร และค่าธรรมเนียม ตัวเลขนักศึกษายังครบ |
| ขอบเขตจังหวัดโหลดไม่ได้ | แจ้ง “ข้อมูลไม่ครบ”: แผนที่ไม่แสดงสีและขอบจังหวัด ตัวเลขในแผงยังครบ |
| แผนที่โหลดไม่ได้ | ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ พร้อมปุ่มลองใหม่ |
| เลือกวิทยาเขต | แผนที่เปลี่ยนเป็น 3 มิติ จัดกรอบวิทยาเขตและรูปของคณะ อาคารของคณะเน้นบนแผนที่ |
| เลือกอาคารของคณะ | กล้อง 2-point ที่อาคาร แผง “คณะในอาคารนี้” และ “สูงราว N ม.” |
| วิทยาเขตไม่มีจุด | นับเหมือนแห่งอื่น ไม่มีหมุด ชิป “ไม่มีจุดบนแผนที่” |
